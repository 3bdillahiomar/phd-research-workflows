# PhD Research Workflows

Reproducible geospatial and CLIMADA workflows supporting PhD research on multi-hazard risk modelling for critical transport infrastructure.

## Case studies

1. UK airport infrastructure
2. UK railway network
3. East African airport and railway infrastructure

## Methods

- Earth observation and remote sensing
- Multi-hazard risk modelling
- CLIMADA impact assessment
- Transport-specific exposure and vulnerability analysis
- Railway network analysis
- Uncertainty, sensitivity and validation analysis

## Repository scope

This repository contains Python scripts, notebooks, configuration files, methodological documentation and reproducible research outputs.

Research documents, administrative records and restricted datasets are maintained separately in approved storage systems.

## Data policy

Confidential, restricted and third-party datasets will not be uploaded. The `data` and `outputs` directories retain only their documentation and placeholder files.
